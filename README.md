# Demiros Tools · Cronos

Módulo para Foundry VTT (v13–v14): calendário do mundo (meses, semana, estações, dias intercalares), controle do tempo como um player, eventos que se repetem e o céu. Funciona sozinho; com o **Atlas** gera a parte astronômica do calendário e as fases das luas.

## Instalar
No Foundry, em **Módulos → Instalar módulo**, cole o manifesto:

```
https://github.com/Demiros-Freitas/cronos/releases/latest/download/module.json
```
